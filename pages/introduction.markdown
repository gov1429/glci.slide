# What is GitLab CI?

GitLab CI/CD is GitLab's built-in tool for Continuous Integration and Continuous Deployment.

<v-clicks fade>

- **Integrated Directly**: No separate server like Jenkins; runs within your GitLab instance.
- **YAML Configuration**: Define pipelines in a `.gitlab-ci.yml` file in your repo.
- **Scalable and Secure**: Supports runners, artifacts, and more.

</v-clicks>

<div class="bg-blue-100 p-4 rounded-lg mt-4 text-blue-800">
Migration from Jenkins: Simpler maintenance, versioned configs, and unified platform.
</div>

# Why Migrate from Jenkins?

Jenkins is powerful but can be complex to manage.

<v-clicks depth="2">

- **Pros of GitLab CI**
  - Built-in to GitLab: No plugins hassle.
  - Git-centric: Pipelines tied to commits/branches.
  - Auto-scaling with runners.

- **Common Pain Points in Jenkins Addressed**
  - Plugin conflicts → Native features.
  - Separate UI → All in one place.

</v-clicks>
